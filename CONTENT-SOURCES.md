## Apresentação de contribuições open source

O hero usa “OSS — open source contributions”, sem sugerir uma contagem total de contribuições. A seção `#open-source` reúne cards de contribuições comprovadas. O número quatro aparece somente dentro da contribuição Nuclei e identifica os templates daquele PR. A lista atual tem uma contribuição confirmada; o link More on GitHub abre a busca pública por PRs de RootKaito.

Para adicionar uma contribuição: incluir um `article.contribution-card` em `.contribution-list`, com repositório, título, descrição factual, status, data e link direto para revisão. Adicionar o título e link à busca em `app.js`. Evitar somar arquivos alterados como se fossem PRs.
